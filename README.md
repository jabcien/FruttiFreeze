# FruttiFrezze Project
## Páginas Incluidas
- **Inicio**: Banner, destacados y testimonios.
- **Nosotros**: Historia, misión, visión y equipo.
- **Productos**: Catálogo con buscador y filtros por categoría.
- **Servicios**: Detalle de servicios y proceso de atención.
- **Galería**: Visualización de imágenes con efecto lightbox.
- **Contacto**: Formulario con validación y mapa.
